# ✨ Lumina

> A small, calm corner of the web. One file. No install. Just open it.

Lumina is a self-contained focus companion that runs entirely in your browser —
no build step, no dependencies, no server, no tracking, works offline. Open
`index.html` and it just works.

![one file, zero dependencies](https://img.shields.io/badge/dependencies-0-7aa2ff)
![works offline](https://img.shields.io/badge/offline-yes-7df0c8)

## What's inside

- 🌌 **Living constellation** — a particle starfield that links up, drifts, and
  follows your cursor. Click to send a ripple of energy through it.
- ⏱️ **Focus timer** — a beautiful progress ring with Focus 25 / Deep 50 /
  Break 5 presets. Set an intention for the session.
- 🎉 **Quiet rewards** — a particle burst and a gentle chime when you finish,
  plus a *sessions today* count and a *day streak* (saved locally).
- 🌬️ **Breathing guide** — a slow inhale · hold · exhale orb for when you need
  to reset. (Press **B**.)
- 🎵 **Generative ambient sound** — a soft evolving drone with random pentatonic
  plucks, synthesized live with the Web Audio API. No audio files. (Press **M**.)
- 🎨 **Five themes** — Aurora, Violet, Ember, Forest, Mono. (Press **T**.)
- 💾 Everything (theme, intention, streak) is remembered in `localStorage`.
  Nothing ever leaves your machine.

## Run it

Just open the file — really:

```bash
# macOS
open index.html
# Linux
xdg-open index.html
# Windows
start index.html
```

Or drag `index.html` onto any browser tab. That's the whole setup.

## Keyboard shortcuts

| Key | Action |
|-----|--------|
| `Space` | start / pause |
| `R` | reset timer |
| `B` | breathing guide |
| `M` | toggle ambient sound |
| `T` | cycle theme |
| `F` | fullscreen |
